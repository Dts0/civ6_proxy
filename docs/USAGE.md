# Windows 客户端使用说明

## 使用条件

- Windows 10 或 Windows 11 x64。
- 房主和所有跨网玩家都运行 Civ6RelayClient。
- 所有人连接同一台公网中转服务器。
- 所有人的 Civ 6 版本、DLC 和模组一致。
- 房主和加入者的客户端都会在连接时配置 Windows 防火墙，允许当前虚拟网段发往本机 UDP `62056` 和 `62900–62999` 的流量，适用于所有网络配置文件。

客户端需要管理员权限来加载官方签名的 WinDivert 驱动，不会向 Civ 6 注入 DLL，也不会修改游戏文件或系统路由。

## 安装

1. 解压 `Civ6RelayClient-windows-x64.zip`。
2. 保留 `Civ6RelayClient` 目录内的全部文件和 `_internal` 目录。
3. 运行 `Civ6RelayClient.exe` 并同意 UAC 提权。

客户端仅把中转地址和昵称保存到 `%APPDATA%\Civ6Relay\config.json`。房间码、房间 ID 和会话令牌不会持久化。

## 界面字段

| 字段 | 填写内容 |
| --- | --- |
| 中转地址 | VPS 的公网 IPv4 或域名，加 UDP 端口，例如 `203.0.113.10:42056` |
| 昵称 | 1–24 个字符，每名玩家使用易于区分的昵称 |
| 房间码 | 房主创建后自动显示；加入者填写收到的 10 位代码 |

状态栏会显示 Civ 6 进程、当前虚拟网段、到中转服的 RTT，以及隧道接收和发送的游戏数据报数量。接收计数在本机注入前增加。

## 房主操作

1. 填写中转地址和昵称，点击“创建房间”。
2. 等待状态变成“中继运行中”。
3. 点击“复制房间码”，通过可信聊天渠道发给其他玩家。
4. 等待所有玩家出现在成员列表且状态为“在线”。
5. 启动 Civ 6，进入“多人游戏 → 局域网”，创建房间。
6. 保持 Civ6RelayClient 运行，不要在游戏过程中点击“断开”。

房主主动断开会立即关闭工具房间；房主网络中断超过 60 秒也会关闭房间。

## 加入者操作

1. 填写与房主相同的中转地址、自己的昵称和 10 位房间码。
2. 点击“加入房间”，确认成员列表能够看到房主和其他玩家。
3. 启动 Civ 6，进入“多人游戏 → 局域网”。
4. 如列表为空，退出局域网列表再进入，或执行一次刷新。
5. 选择房主创建的游戏并加入。

## 正常状态

- “中继运行中”：控制连接、UDP 保活和 WinDivert 均已启动。
- “Civ 6：未运行”：工具已就绪，但尚未检测到游戏进程；启动游戏即可。
- RTT 有数值：中转服能够正常返回保活包。
- 游戏收发计数增长：发现包或会话包正在经过中转。

## 退出

先退出 Civ 6 房间，再点击工具的“断开”。关闭窗口也会停止 WinDivert、发送离开消息并恢复正常网络处理。
